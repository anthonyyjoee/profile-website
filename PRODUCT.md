# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js (App Router), React 19, TypeScript, Tailwind CSS v4, Three.js, Lucide React

## Users

Tech recruiters, engineering hiring managers, and tech leads evaluating full-stack competence for engineering roles. They typically scan within 30–60 seconds, looking for verified technical depth, architectural soundness, production code quality, and clear contact links.

## Product Purpose

Establish a high-craft personal engineering presence and portfolio. The site proves end-to-end full-stack capabilities (React, Next.js, TypeScript, Node, Go, APIs) and drives visitors to inspect GitHub repositories and get in touch via email and social channels. Success is measured by recruiter/manager engagement, code inspection, and inbound interview conversations.

## Positioning

Full-Stack Engineer with a dual focus: robust backend and API systems engineering (Go, Node, REST/GraphQL) combined with modern, high-polish web frontend execution (Next.js, TypeScript, interactive WebGL/Three.js).

## Operating Context

Evaluated on desktop and mobile devices during hiring and screening workflows, often alongside resumes, LinkedIn, and GitHub profiles. Visitors need instantaneous clarity on tech stack, project roles, and direct access to source code.

## Capabilities and Constraints

- Curated project showcases with live preview links, source code repositories, and technical breakdowns.
- Interactive procedural 3D hero element built in Three.js with zero heavy asset downloads.
- Direct contact integrations: Email copy/mailto, social links, and prominent GitHub entry points.
- Instant load times, strict type safety, semantic HTML, and mobile-first responsiveness.

## Product Principles

1. **Proof Over Claims**: Let real project architecture, working demos, and clean GitHub code demonstrate competence rather than self-assessed ratings.
2. **Instant Scannability, Optional Depth**: Ensure key skills, roles, and project summaries are understood in 15 seconds, with architectural details accessible for technical reviewers.
3. **Frictionless Outreach**: Keep Email, GitHub, and social channels immediately reachable from anywhere on the page.
4. **Uncompromised Performance**: High-craft interactions and 3D visual elements must run at 60 FPS and never degrade page load or mobile usability.
